## Roadmap · 로드맵

- [ ] **Bayesian Optimization** — Gaussian process surrogate + expected improvement; the standard for expensive black-box objectives (e.g., hyperparameter tuning). <sub>가우시안 프로세스 대리모델 + 기대개선 획득함수</sub>
- [ ] **CMA-ES** — covariance matrix adaptation evolution strategy; state of the art for continuous black-box optimization. <sub>공분산 행렬 적응 진화 전략</sub>
- [ ] **NSGA-II** — multi-objective optimization with Pareto fronts. <sub>파레토 전선 기반 다목적 최적화</sub>
- [ ] **Constrained optimization** — penalty & barrier methods. <sub>제약 조건 처리 (벌점/장벽 기법)</sub>
- [ ] **Gradient-based deep learning optimizers** — SGD → Momentum → Adam, from scratch. <sub>딥러닝 최적화기 계보를 밑바닥부터</sub>

Each item lands here as a tested implementation + a short study note comparing it against the Level 1–3 baselines.
<sub>각 항목은 테스트된 구현 + Level 1–3 기준선과의 비교 노트 형태로 추가됩니다.</sub>
