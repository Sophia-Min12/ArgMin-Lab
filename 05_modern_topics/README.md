# Level 5 · Modern Topics 🚧

> Research-grade optimizers used in today's ML pipelines and papers.

## Roadmap

- [ ] **Bayesian Optimization** — Gaussian process surrogate + expected improvement; the standard for expensive black-box objectives (e.g., hyperparameter tuning).
- [ ] **CMA-ES** — covariance matrix adaptation evolution strategy; state of the art for continuous black-box optimization.
- [ ] **NSGA-II** — multi-objective optimization with Pareto fronts.
- [ ] **Constrained optimization** — penalty & barrier methods.
- [ ] **Gradient-based deep learning optimizers** — SGD → Momentum → Adam, from scratch.

Each item lands here as a tested implementation + a short study note comparing it against the Level 1–3 baselines.
